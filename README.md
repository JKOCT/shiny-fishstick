# ✨ Stardust Garden

A tiny incremental (idle) game that runs in your web browser.

## How to play
1. Download `index.html`.
2. Double-click it. It opens in your browser.
3. Click the star to gather stardust. Spend it on **Helpers** (they gather stardust for you) and **Upgrades** (your clicks get stronger).

Your progress saves automatically, and your helpers keep working while you're away.

## How to change the game
Open `index.html` in any text editor (Notepad, TextEdit, or VS Code). Look for the
**GAME SETTINGS** section. There you can:

- rename helpers or change their emoji
- change prices (`cost`) and output (`perSecond`, `clickBonus`)
- add a new helper by copying a line and editing it
- make the game harder or easier with `PRICE_GROWTH`

Save the file and refresh your browser to see the change.
To change the colors, edit the values under `:root` near the top of the file.
